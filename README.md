## Handwritten Digit Classification with PyTorch
A beginner-friendly deep learning project using PyTorch to classify handwritten digits from the Digit Dataset (Kaggle).
This project showcases how a simple fully connected neural network can achieve 86.61% accuracy with proper training and optimization.
# Features
 Lightweight architecture using nn.Flatten + nn.Linear
 Trained from scratch — no pre-trained models
 Clean training and evaluation pipeline
 Achieved 86%+ accuracy on the test set
# Tech Stack
Python 
PyTorch 
Kaggle Dataset
