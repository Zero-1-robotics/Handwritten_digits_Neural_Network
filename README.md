# Handwritten Digit Classification with PyTorch

This project a deep learning implementation using PyTorch to classify handwritten digits from the Digit Dataset on Kaggle.  
A simple fully connected neural network was trained from scratch and achieved an accuracy of 86.61% on the test set.

## Features
- Lightweight neural network using nn.Flatten and nn.Linear
- Trained from scratch without pre-trained models
- Structured training and evaluation pipeline
- Achieved over 86% accuracy

## Tech Stack
- Python  
- PyTorch  
- Kaggle Dataset

## Project Goals
- Build and train a fully connected neural network  
- Work with a real-world dataset  
- Understand each step of model training and evaluation  
- Establish a foundation for more advanced architectures
